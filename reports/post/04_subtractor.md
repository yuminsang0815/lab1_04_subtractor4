# 실험 전 레포트: 4비트 감산기

작성일 2026-09-19.

## 목적과 예상값

두 4비트 입력 `a[3:0]`, `b[3:0]`에 대해 산술 뺄셈을 수행하여 4비트 차 `d[3:0]`와 1비트 빌림수 `bor`를 구합니다. top은 `sub_4bit`입니다. 피감수보다 감수가 엄격히 클 때(`a < b`)만 빌림수 1을 생성하며, 동일한 값(`a == b`)은 빌림수가 발생하지 않습니다.

| a | b | bor | d | 비고 |
|---:|---:|---:|---:|---|
| 0000 (0) | 0000 (0) | 0 | 0000 (0) | 동일 입력 감산 |
| 0000 (0) | 0001 (1) | 1 | 1111 (15) | 음수 발생 (2의 보수 언더플로) |
| 1000 (8) | 0000 (0) | 0 | 1000 (8) | 양수 결과 |
| 1111 (15) | 1111 (15) | 0 | 0000 (0) | 최댓값 일치 조건 |

## 환경과 입력 파일

Windows, Git 2.55.0, VS Code 1.136.1, XSim 2026.1을 사용했습니다. 공개 템플릿의 커밋 `740aef5`를 공백이 있는 별도 폴더에 새로 clone했습니다. `LAB1.code-workspace`는 `vivado_2026_1/04_subtractor4`를 PROJECT, `common`을 COMMON으로 연결합니다.

[RTL](../../src/sub_4bit.v), [TB](../../sim/tb_sub_4bit.sv), [XDC](../../constraints/sub_4bit.xdc)를 사용했습니다. TB top은 `tb_sub_4bit`이며 루프 변수 0부터 255까지 10ns 간격으로 인가하여 256가지 조합을 전수 검사합니다. 대소 비교 및 감산 기대 모델과 비교하여 불일치 시 `$fatal`로 종료하고, 2560ns에 정상 종료합니다.

## 실행과 관찰

VS Code 새 창에서 workspace를 열고 slang-server와 VaporView를 활성화했습니다. 저장 후 Terminal → Run Task...의 Check tools, Simulate를 실행하고 Open waveform으로 VCD를 열었습니다. `a,b,bor,d`를 추가하고 Zoom to Fit와 ns 단위를 선택했습니다.

실제 [VS Code 작업 실행 로그](../../evidence/04/vscode/simulation.txt)에서 `LAB1_PASS sub_4bit cases=256`과 2560ns 종료를 확인했습니다.

| 구간(ns) | a (hex) | b (hex) | bor, d (hex) | 해석 |
|---|---|---|---|---|
| 0–10 | 0 | 0 | 0, 0 | 동일 피연산자: bor=0 |
| 10–20 | 0 | 1 | 1, F | 0-1=-1: bor=1 점등 및 4'hF 표출 |
| 170–180 | 1 | 1 | 0, 0 | 1-1=0: bor 비활성화 |
| 180–190 | 1 | 2 | 1, F | 1-2=-1: bor 활성화 전환 |

전환 순간 대신 구간 중간에서 커서를 읽었습니다. 파형만 눈으로 맞아 보이는 것에 더해 자동 비교 256건과 정상 종료를 함께 확인했습니다.

## 보드 실험 계획

DIP1~4(a[3:0]), DIP5~8(b[3:0]), LED1(bor), LED2~5(d[3:0]), LVCMOS33입니다. Vivado에서 같은 TB를 실행한 다음 bit를 생성하고 하드웨어에 주입합니다. 동일 값을 설정했을 때 bor LED가 꺼져 있는지 확인하고, b를 1 크게 조작했을 때 bor LED1이 켜지는 현상을 사진·영상에 담을 계획입니다.
